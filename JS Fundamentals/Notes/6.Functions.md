Function statement : 

	function name(){
		console.log("hello)
	}

Function Expression : 

	var a = function name(){
		      console.log("hello)
	        }

Main diff is in hoisting of both above.


Anonymous Function :

	function (){
		console.log("hello")
	}

- this will give syntax error that "function statement must have name".
- we can assign Anonymous Function to variable to create function expression 


- Diff between Parameters and Arguments

	function hello(name, surname){ // these are parameters
		log(name, surname)
	}

	hello('yug',sudani') // these are arguments
