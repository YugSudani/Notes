- it is used to write multiple statement where only one is expected

- Shadowing : when we declare same variable in child of it's parent 
```
------------------------ var has global scope
var z = 10;
{
  var z = 20; // this line is shadowing outer variable z
  console.log(z); //20
}
console.log(z); //20

-------------------------- let has block scope
let z = 10;
{
  let z = 20; // this line is shadowing outer variable z but let has block scope
  console.log(z); //20
}
console.log(z); //10
```


trick que : funcntion scope creates its own execution context

```

var c = 20;

function print() {          
  var c = 30;          // funcntion scope creates its own execution context
  console.log(c); // 30
}
print();
console.log(c); // 20
---------------------------- modifying same
function print() {
  c = 30;
  console.log(c); // 30

}
print();
console.log(c); // 30

```

- SO FUNCTIONAL BLOCK AND NORMAL BLOCK { } ARE DIFF


- simple concept each block has its own space in memory, so we goes to find it finds in own memory first.
